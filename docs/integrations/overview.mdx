# Integrations

Integration docs are **connector-specific**. Each guide covers installation, authentication, events, tools, webhooks, and examples.

<InfoBox>
Connectors <strong>emit events</strong> and may expose tools. They never run FlowRunner. See <a href="/docs/developer/concepts/connectors">Connectors</a> and <a href="/docs/guides/event-driven-triggers">Event-Driven Triggers</a>.
</InfoBox>
