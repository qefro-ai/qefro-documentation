# Architecture

This page is a short entry point. The canonical deep dive is
**[Qefro architecture](/docs/architecture/overview)** (including the
**solutions plane**: solution-service, managed apps, Marketplace, portal
renderer, and capability registries).

```mermaid
flowchart TB
  subgraph Config[Admin Console]
    WS[AI Workspaces]
    Mkt[Marketplace installs]
    KB[Knowledge]
    Tools[Business Tools]
  end

  subgraph Runtime[Qefro Runtime]
    RAG[Hybrid RAG]
    FR[FlowRunner]
    Inv[Tool invoker]
  end

  subgraph Apps[Solutions plane]
    SS[solution-service]
    App["/qefro SDK apps"]
  end

  subgraph Channels[Channels]
    Widget[Website widget]
    WA[WhatsApp]
    Portal[Internal Portal]
  end

  WS --> Runtime
  Mkt --> SS
  SS --> App
  KB --> RAG
  Tools --> Inv
  Channels --> Runtime
  FR --> Inv
  Inv --> App
  Inv -->|REST / OpenAPI / SDK Connection| Ext[Your APIs]
```

<InfoBox>
**Two tool paths:** Business Tools (REST/OpenAPI or Backend SDK **webhook**) vs
installable **SDK apps** (managed `/qefro`). See [Core concepts](/docs/introduction/concepts).
</InfoBox>
