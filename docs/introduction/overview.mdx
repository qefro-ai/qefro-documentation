# What is Qefro?

Qefro is an **AI Workspace platform** for organizations. You configure knowledge,
permissions, and tools once, then ship three product surfaces:

- **Assistants** — **Customer AI** (website widget, WhatsApp) and **Employee AI**
  (branded Internal Portal), grounded in workspace knowledge with citations
- **Marketplace Apps** — metadata packages (`qefro app init`) published to
  **Marketplace**, installed per workspace, executed by **Qefro Runtime**
  (UI, entities, storage, Business Flows, events, CRM, Automation)
- **Secure actions** — **Business Tools** (REST / OpenAPI / Backend SDK webhook)
  for connecting **external** ERP / POS / CRM systems over `/qefro`

Assistants answer questions and run **Business Actions**. Marketplace Apps
own vertical metadata (reservations, listings, bookings) while the platform
owns Customer Hub (People), campaigns, organization workflows, and Runtime
execution. The SDK is for **external** systems, not for building Marketplace
Apps.

<InfoBox>
**Configure once. Deploy everywhere.** Workspaces isolate knowledge and tools.
Install apps from Marketplace without forking per tenant. Events, chat, and
schedules enter the same Runtime.
</InfoBox>
