# Configuration

| Layer | What you configure |
| --- | --- |
| Admin Console | Workspaces, knowledge, channels, RBAC, SDK connections, enable flows |
| Backend SDK | Tools, flows, customer provider, middleware (code) |
| Connectors | External credentials, webhook secrets, emit target |
| Platform env | Self-host infrastructure only |

Flow **Prompt Overrides** and enable toggles are console-side and survive SDK `name` renames (identity is flow `id`).
