# Knowledge Base

Train your assistant by adding **documents** to a workspace. Qefro chunks and indexes them with **hybrid RAG** (lexical + vector) and returns **citations** in answers.

## Common tasks

| Task | Notes |
| --- | --- |
| Upload files | PDF, DOCX, Markdown, TXT |
| Add text / crawl | Console flows for raw text and site crawl |
| Reindex | After content changes |
| Verify quality | Admin chat — check citations and refusals |

<Warning>
Validate retrieval quality in the Admin Console **before** enabling public widget or WhatsApp.
</Warning>
