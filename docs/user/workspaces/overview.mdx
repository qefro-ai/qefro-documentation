# Workspaces

An **AI Workspace** is the isolation boundary for knowledge, Business Tools, conversations, and channel bindings (widget, WhatsApp, Employee AI).

## Common tasks

| Task | Where |
| --- | --- |
| Create a workspace | Admin Console → Workspaces |
| Bind Customer AI | Workspace → Widget / WhatsApp settings |
| Grant team access | Organization → Teams → workspace grants |
| Tune instructions | Workspace system prompt / instructions |
