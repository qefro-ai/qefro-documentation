# Agents & assistants

Qefro assistants are **workspace-bound**:

- **Customer AI** — public website widget and WhatsApp
- **Employee AI** — Internal Portal for org members

## Configure behavior

- Workspace instructions / system prompt
- Enabled Business Tools and Flows
- Handoff webhooks for human takeover
- Branding (widget + portal)
