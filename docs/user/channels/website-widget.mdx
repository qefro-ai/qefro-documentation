# Website widget

Embed Customer AI with a publishable **widget token** from the Admin Console.

## Operator steps

1. Open the workspace → **Widget** settings.
2. Copy the embed snippet / token (rotate if leaked).
3. Add the script to your site (see deploy guide).
4. Optionally configure `identify()` for logged-in users.
