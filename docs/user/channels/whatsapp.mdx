# WhatsApp

Customer AI on **WhatsApp** uses Meta Cloud API webhooks into Qefro.

<Warning>
WhatsApp requires a plan entitlement (Growth+) and a verified webhook. Validate the workspace brain on the widget first.
</Warning>

## Operator steps

1. Confirm plan supports WhatsApp.
2. Configure Meta app + webhook URL on `api.qefro.com`.
3. Bind the phone number to a **Support** workspace.
4. Send a test message and verify citations / tools.
