# Approvals

When a Business Flow includes an **`approval`** step, the run pauses until an **Owner or Admin** approves in **Flow Runs**.

<InfoBox>
Approvals are part of flow execution — not a separate product. Engineers declare <code>approval</code> steps in the Backend SDK; operators act on them in the console.
</InfoBox>

## Operator steps

1. Open **Business Tools → Flow Runs** (or Approvals queue).
2. Open a run with status **waiting_for_approval**.
3. Review variables / timeline → **Approve** (or cancel the run).
4. The customer receives the next message on their channel (widget or WhatsApp).
