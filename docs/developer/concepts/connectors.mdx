# Connectors

A **connector** adapts an external product (Shopify, Odoo, HubSpot, …) into Qefro:

1. Authenticate to the external API
2. Map webhooks / polls → **namespaced events**
3. Optionally expose tools via Backend SDK or REST integrations
4. **`emit()` only** into the Qefro event bus

<Warning>
Connectors must not start flows, call FlowRunner, or embed a second orchestrator. Use connector-kit EventEmitter or POST /api/v1/org/events/ingest/:tenant_id.
</Warning>
