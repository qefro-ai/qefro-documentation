# Challenges

Qefro orchestrates challenges; **your** Customer Provider remains the authority.

- Implicit: tool with `auth: 'required'`
- Explicit: flow `challenge` step
- Protocol: challenge → customer response → `tool.resume`

Guides:

- [Challenge & Resume](/docs/business-tools/challenge-resume)
