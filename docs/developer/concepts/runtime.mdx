# Runtime

The **Qefro Runtime** is the single execution engine for:

- **Marketplace Apps** — metadata UI, entity tools, managed storage
- AI tool-loop calls into Business Tools
- **Business Flows** (FlowRunner): ask, tool, condition, delay, approval, challenge, complete
- Entry from **conversation intent**, **events**, **schedules**, and **webhooks**

<InfoBox>
Marketplace App workflows compile into the <strong>same</strong> BusinessFlow / FlowRunner as SDK-advertised flows. External systems use an SDKAdapter on <code>tool.invoke</code>; metadata apps use Runtime entity capabilities — no <code>/qefro</code> server.
</InfoBox>
