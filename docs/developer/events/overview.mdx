## Operate

| Method | Path | Purpose |
| --- | --- | --- |
| GET | `/api/v1/org/events` | List |
| GET | `/api/v1/org/events/:id` | Get |
| POST | `/api/v1/org/events/:id/retry` | Retry failed |
| POST | `/api/v1/org/events/:id/replay` | Replay as new row |
| POST | `/api/v1/org/events/replay` | Range replay |
