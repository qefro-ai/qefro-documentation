# Observability

| Signal | Where |
| --- | --- |
| Tool execution logs | Admin Console + `GET /api/v1/tools/:id/logs` |
| Flow Runs timeline | Admin Console Flow Runs |
| Orchestration events | `GET /api/v1/org/events` |
| Audit logs | [Audit logs](/docs/security/audit-logs) |
| Prometheus metrics | `GET /metrics` (ops) |
