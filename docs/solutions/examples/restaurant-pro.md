# restaurant-pro (removed)

The SDK-hosted takeaway Marketplace App (`hosting: managed`, `src/`, `/qefro`)
is no longer part of the platform.

Build Restaurant Pro as metadata:

- [restaurant-pro-runtime](/docs/solutions/examples/restaurant-pro-runtime)
- [Build your first app](/docs/solutions/build-your-first-app)
- [Runtime vs SDK](/docs/solutions/runtime-vs-sdk)

To connect an existing restaurant ERP or POS, use an
[SDK Connection](/docs/developer/external-sdk-connection).
