# Manifest evidence matrix

[Marketplace handbook](handbook.md) is the landing page. This matrix is the evidence-first index for [Manifest](manifest.md), [HTTP tools](http-tools.md), [Settings](settings-reference.md), [Auxiliary files](auxiliary-reference.md), [Events](events.md), [Capabilities](capabilities.md), and [Security](security.md).

Citations are relative to the multi-repository workspace, with verified source line numbers (`repository/path:line`). They refer to the checked-out implementation, not a release promise. Tests below were inspected, not executed. **Runtime** means an actual consumer was traced; **metadata** means accepted/persisted but no operational consumer established; **partial** means producer and consumer contracts differ; **rejected** means a validation gate rejects it. A struct, comment, constant, example, or passing parser test alone is not runtime evidence.

## Verification boundaries

The inventory records every owned schema attribute separately, including untagged alternatives, arbitrary-key maps and runtime-reserved keys. Workflow step schemas, entity schemas and UI widget properties belong to their dedicated handbook references. Packaging, publishing and install lifecycle are linked rather than duplicated here. No external service, credentials, deployment or production test was used for this documentation audit.
