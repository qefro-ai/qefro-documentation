# WhatsApp commerce

**Outcome:** Customers discover products, get policy-correct answers, check orders, and complete guided commerce tasks on **WhatsApp** — backed by the same workspace Runtime as your website.

## Building blocks

| Piece | Role |
| --- | --- |
| Customer AI workspace | Knowledge + instructions |
| WhatsApp channel | [Configure WhatsApp](/docs/user/how-to/configure-whatsapp) |
| Catalog / order tools | Shopify, WooCommerce, or custom SDK |
| Flows | Checkout help, abandoned cart, returns |
| Events | Cart/checkout webhooks → FlowRunner |

## Operator path

1. [Create an AI agent](/docs/user/how-to/create-ai-agent) for commerce/support.
2. Connect store — [Connect Shopify](/docs/user/how-to/connect-shopify) or WooCommerce integration.
3. [Configure WhatsApp](/docs/user/how-to/configure-whatsapp) on that workspace.
4. Test order tracking and FAQs on a real device.
5. Add journeys: [Abandoned cart](/docs/solutions/abandoned-cart), [Order tracking](/docs/solutions/order-tracking), [Refund automation](/docs/solutions/refund-automation).
