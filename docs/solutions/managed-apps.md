# Managed apps

The **platform-hosted `/qefro` Marketplace App** model (`hosting: managed`)
is removed. There is no Marketplace App SDK server.

**Build a Qefro Marketplace App with metadata.** See
[Runtime vs SDK](/docs/solutions/runtime-vs-sdk) and
[Build your first app](/docs/solutions/build-your-first-app).

Use the **Qefro SDK** only to connect an external ERP, POS, or CRM:
[External SDK Connection](/docs/developer/external-sdk-connection).
