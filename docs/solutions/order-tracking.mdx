# Order tracking

Customers ask where their order is; the assistant calls your order API via a Business Tool or flow.

## Architecture

For **Shopify** Marketplace: customer chat → `list_my_orders` / `get_my_order` → generic HTTP executor → Admin API filtered by Hub `{person.email}` → ownership check.

For **SDK / custom API**: chat intent → flow or tool_loop → order_status_check → cited/status response.

See [HTTP tools](/docs/solutions/http-tools) and [Connect Shopify](/docs/user/how-to/connect-shopify).

## Prerequisites

- Order status API or Backend SDK tool
- Workspace with tool enabled
- Clear intent utterances

## Installation

1. Complete [User getting started](/docs/user/getting-started) for the Support (or commerce) workspace.
2. Connect channels required by this solution.
3. Register tools / connectors (see links below).
4. Declare and **enable** flows; Accept versions after sync.
5. Run a dry-end-to-end test in a non-production workspace when possible.

## Flows

ask order_id → tool order_status_check → complete with `{{status}}`

## Deployment

- Production checklist: [Production deployment](/docs/guides/production-deployment)

## Troubleshooting

- No answer / weak citations → knowledge coverage ([Knowledge Base](/docs/user/knowledge-base/overview))
- Tool failures → tool logs + SDK webhook health
- Event flow never starts → namespaced name, Enabled+Valid+Accepted, `when` predicate ([Events](/docs/guides/event-driven-triggers))
- Approval stuck → Owner/Admin role ([Approvals](/docs/user/approvals/overview))
